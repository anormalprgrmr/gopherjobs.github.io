Description

Airteam is a fast-growing Berlin SaaS startup with an AI-powered cloud platform for roofers and solar planners. Our customers turn simple drone data into actionable 3D models and measurement reports. As a Full Stack Software Engineer with a front-end focus, you'll build the web applications that take projects from drone data acquisition to customer delivery, and help create a digital, climate-neutral product.

Tasks

  • Build web applications that manage projects from drone data acquisition to customer delivery

  • Work with UI/UX and PMs to ensure technical feasibility of designs and clear, actionable tickets

  • Design and implement frontend and backend, integrate both, test and debug

  • Maintain and improve our CI/CD pipeline and container-based architecture

  • Write automated tests and technical documentation

  • Find and fix bugs and performance bottlenecks

  • Build reusable code and libraries

Requirements

  • Proficient in JavaScript (ES6/7), HTML5, CSS3

  • Experience building SPAs with Vue.js

  • Experience with Python and Flask or FastAPI

  • Knowledge of relational databases (PostgreSQL) and REST API design

  • Experience with Docker

  • Understanding of unit and functional testing (TDD)

  • Comfortable in an agile, product-focused team, with a drive for software craftsmanship and quick learning

  • Fluent English (written and spoken), as our team works internationally (German is a plus, but not required)

Nice-to-have

  • TypeScript

  • Django and Django Rest Framework

  • MongoDB

  • Kubernetes

  • GCP

  • Distributed systems and microservices
