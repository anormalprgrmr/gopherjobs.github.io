THE OPPORTUNITY At NavVis we build mobile mapping devices, including NavVis VLX and NavVis MLX, that operators use to capture and process spatial data in the field. This is a full stack engineering role covering the UI and backend stack that powers these devices. You will work across the stack, from the Angular and TypeScript UI operators use in the field to the Python and C++ backend that handles mapping, sensor data processing, and visualization. The software runs on Linux, across both x86 and arm64 platforms.

You will design and build the client-server architecture that connects high-performance robotics computations with a simple, interactive web interface, working closely with our in-house UI and UX designers to shape the mapping experience.

If you enjoy moving between frontend and backend work, and want hands-on exposure to robotics alongside modern web development, you will have the scope to shape how operators interact with NavVis's mapping devices.

How You Will Make An Impact

  • Build and maintain the UI application that powers NavVis VLX, NavVis MLX, and other mobile mapping devices, using Angular, TypeScript, HTML, and CSS
  • Develop the Python and C++ backend for sensor integration, communication, and data visualization on Linux-based x86 and arm64 mapping devices
  • Design and build the client-server architecture that connects high-performance robotics computations with a simple, interactive web interface
  • Shape the mobile mapping experience by collaborating closely with in-house UI and UX designers

What Will Help You Succeed In The Role

  • Master's or Bachelor's degree in computer science, electrical engineering, or a related field
  • 5+ years of professional software engineering experience, including hands-on web application development
  • Strong experience with Angular, TypeScript, and JavaScript, including common JS testing frameworks such as Playwright or Cypress
  • Strong Python skills
  • Solid knowledge of Linux systems, including comfort with terminal tools and system-level debugging
  • Experience with C++, Java, or a similar statically typed, object-oriented language

Would be an added benefit

  • Exposure to robotics, handheld or embedded devices, or sensor systems such as LiDAR, cameras, or IMUs
  • Interest in mobile mapping and spatial data, shown through relevant projects or work
