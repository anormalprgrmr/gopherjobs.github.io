Description

Deine Rolle

Du gestaltest und betreibst die digitale Infrastruktur, die die internen und externen Systeme verbindet — von Cloud- und SaaS-Plattformen über Legacy-Applikationen bis hin zu modernen APIs. Du trägst dafür Sorge, dass Daten und Prozesse zuverlässig, skalierbar und wartbar fließen.

Es werden überwiegend Schnittstellen, Microservices und Systemintegrationen entwickelt. Aufgabe des Teams ist es, eine bestehende komplexe IT-Schnittstellen-Architektur über die Middleware zu vereinfachen. Hierzu gehört der Abbau, Umbau, Ersatz, Neuentwicklung von Schnittstellen und Services zwischen den Systemen. Ganz nach dem Motto: "You build it, you run it"

Deine Aufgaben

  • Entwurf, Entwicklung und Betrieb von Schnittstellen zwischen internen und externen Systemen – SaaS, Cloud und On-Premise
  • Entwicklung von Middleware , Backend-Services und APIs sowie deren Anbindung an bestehende Systemlandschaften
  • Umsetzung moderner Integrationsarchitekturen mit REST, GraphQL oder ereignisbasierten Ansätzen wie Message Queues und Pub/Sub
  • Erweiterung von Plattformen durch Custom Code und Plugins, z.B. in Shopify
  • Konfiguration und Weiterentwicklung von iPaaS-Plattformen wie Logic Apps, Boomi oder n8n
  • Automatisierung von Geschäftsprozessen durch einen Mix aus fertigen Tools und eigenem Code
  • CI/CD, Cloud Betrieb und Infrastructure as Code im Tagesgeschäft
  • Monitoring und Alerting für produktive Schnittstellen sowie schrittweise Migration von Legacy-Systemen in moderne Stacks

Dein Profil

Must-have

  • Mehrjährige Backend-Erfahrung mit Python (FastAPI, Flask)
  • Sicheres Verständnis von API-Design und Integrationsmustern mit REST, Webhooks, Message Queues, Pub/Sub
  • Praxiserfahrung mit mindestens einer iPaaS-Plattform, z.B. Azure Logic Apps, Boomi, SAP Integration Suite oder n8n
  • Vertraut mit DevOps-Prinzipien , CI/CD, Containerisierung, Monitoring sowie gängigen Cloud-Plattformen (GCP, Azure, AWS)
  • Eigenständige, lösungsorientierte Arbeitsweise mit dem Willen, Verantwortung zu übernehmen

Nice-to-have

  • TypeScript/Node.js, C# vorteilhaft
