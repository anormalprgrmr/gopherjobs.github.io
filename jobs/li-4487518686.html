Responsibilities The Engine team develops and maintains core components of the Workato Recipe runtime. Scope includes recipe execution, DSL, event pulling, webhook processing, and job execution. The team owns trigger and event infrastructure that defines how integrations start and react to external events. Current focus: modernization of a high-throughput platform to improve reliability, scalability, and long-term evolvability. Work is platform-oriented and directly impacts runtime performance and system correctness.

In This Role, You Will Also Be Responsible To

  • Design and implement distributed backend systems in Go with deep consideration of performance and memory behavior.
  • Work on runtime-level components operating under high concurrency and throughput.
  • Apply in-depth knowledge of Go internals (scheduler, memory model, garbage collection behavior) to improve system efficiency.
  • Design and optimize concurrent workflows using goroutines, channels, synchronization primitives, and context propagation.
  • Analyze and optimize slice usage, memory allocations, and data structures for performance-critical paths.
  • Improve execution engine for custom third-party code (isolation, performance, feature extensions).
  • Modernize runtime components with focus on modularity, structured architecture, and observability.
  • Improve trigger configuration and execution across webhooks and polling mechanisms.
  • Integrate and optimize data storage solutions (Postgres, S3, DynamoDB, Kafka, ClickHouse).
  • Identify bottlenecks, race conditions, deadlocks, and performance degradation in distributed systems.
  • Own initiatives end-to-end, from design to rollout and production support.
  • Conduct code reviews with emphasis on correctness, concurrency safety, and performance characteristics.
