Description

We are looking for an experienced Data Engineer to join a large-scale data transformation programme on an initial 12-month contract.

You will be responsible for designing, developing and maintaining scalable data pipelines and data platforms, working closely with Data Architects, Engineers and business stakeholders.

Key Responsibilities

  • Design and develop scalable data pipelines and ETL/ELT processes
  • Build and maintain modern cloud-based data platforms
  • Develop data solutions using Python and SQL
  • Work with large and complex datasets
  • Integrate data from multiple sources and systems
  • Support data modelling and data architecture initiatives
  • Optimise data pipelines for performance and reliability
  • Work closely with Data Architects and other technical teams
  • Ensure data quality, security and governance standards are maintained

Required Experience

  • Strong commercial experience as a Data Engineer
  • Strong Python and SQL skills
  • Experience building data pipelines and ETL/ELT processes
  • Experience with Azure, AWS or GCP
  • Experience with Databricks, Snowflake or similar cloud data platforms
  • Strong understanding of data modelling and data warehousing
  • Experience working with large-scale enterprise data environments
  • Good understanding of data integration and data quality
  • Strong communication and stakeholder management skills
